# forge 异构联邦层（federation）设计规格

## 1. 问题定义：为什么不能把异构 CLI 当成函数调用
CLI 不是纯函数，失败模式盘点：**沙箱拒读**——opencode 对工作目录外读取 auto-reject，agent 反复重试探索，静默烧 token；**协议不兼容**——claude code 需要 Anthropic 端点，`ANTHROPIC_BASE_URL` 误拼 `/v1` 得 404 却被渲染成「模型不存在」；settings 的 `env` 覆盖进程环境变量；**厂商鉴权**——pi 自带 provider 凭据，各家密钥来源互不相通；**输出噪声**——ANSI、TUI 框线、工具日志、进度条混入 stdout；**超时挂起**——网关 SSE 不显式关连接即永久挂起，逐字节转发拖死长响应；**静默降级**——退出码 0 不代表交付（可能只输出道歉）。

## 2. Worker 描述符
每个 CLI worker 声明为一条 config 行（复用 Row 模型，整行替换不深合并）：`id/name`；`exec`（可执行路径）；`args_template`（含 `{task}` 占位）；`cwd`；`protocol`（oneshot-stdout / settings-gateway）；`env`（如 `ANTHROPIC_BASE_URL`、`CLAUDE_CONFIG_DIR`）；`capabilities` 标签（read/write/shell/plan/review）；`cost_tier`（cheap/standard/premium）；`permission_tier`（ro/workspace/full）；`health`（探测命令+期望退出码）；`timeout_sec`；`needs_evidence_copy`（证据须先复制进工作区）。

## 3. 任务派发
任务书是单段文本，任何 CLI 都接得住：**角色与交付物**→**证据约束**（「只读工作区内以下文件，工作区外被拒即停手，不得继续探索」）→**三条纪律固化进模板**：1) 只读证据，引用路径与行号；2) 禁止编造——无证据写「未找到」，不得补全；3) 有界探索——最多 N 次工具调用，超限即输出当前结论。末尾要求以 `<<<RESULT>>>` 包裹正文。证据文件由编排者预先复制进工作区（吸收 DESIGN.md 实测坑 4）。

## 4. 输出归一
清洗管线：剥 ANSI（`\x1b[...m`）→ 去 TUI 框线（Box-drawing 字符连续行）→ 去进度条（`\r` 重写行只留终态）→ 去各家工具日志行（如 `Tool:` 前缀）→ 定位 `<<<RESULT>>>` 提取正文。**成功交付 ≠ 退出码 0**：`success = 退出码 0 且正文非空 且超长度阈值 且不含道歉/错误指纹`（"模型不存在"、`[stopped: max_steps]` 等），再交审查 worker 复核。dsh 等无退出码语义的只按正文判定。

## 5. 失败处理
按错误类别降级（沿用 ModelRouter 的 retryable 语义）：**超时/挂起**——外层 watchdog 超时杀进程组（Windows `taskkill /T`），不等待；**协议错**（非 2xx、输出无法解析）——该 worker 进冷却，换同能力档下一个；同错两次从本轮剔除；**模型错**（429/503/网络）——指数退避重试一次（0.5s 起、上限 4s），再换档。**重试边界**：只重试可重试类错误，400 类提示错误不重试；每任务 `max_attempts × cost_tier` 封顶；重试不重复扣 spawn 预算。

## 6. 成本与配额
策略数据化而非硬编码：config 行 `routes` = `{match: {tags, tier}, workers: [...], reviewer: [...]}`。「贵模型只做审查」= `reviewer: [premium]`，workers 全用 cheap 档。每 worker 挂 `daily_budget`，耗尽自动降档。策略是配置行，改策略只改 config，不动代码。

## 7. 编排拓扑
单一 Orchestrator 派活、归一、审查，worker 默认**无权再派生**（权限天花板钳制，复用 `Policy.child()`）。仅 Orchestrator 可 fan-out；`depth ≤ max_depth`，`spawn_budget` 共享递减防预算爆炸；每个 worker 结果经 `sanitise_child_output` 去毒后才进上下文；派发与回收落 `federation_spawn` / `federation_result` 事件进 Session JSONL。

## 8. 与既有模块的接口
- `forge/federation/registry.py`：`WorkerRegistry.register(spec)`、`pick(task, tags) -> list[Worker]`、`healthcheck(w) -> bool`
- `forge/federation/runner.py`：`run_worker(w, taskbook) -> WorkerResult`、`clean_stdout(raw) -> str`、`judge_success(res) -> bool`
- `forge/federation/orchestrator.py`：`orchestrate(task, budget) -> FederatedReport`
- 复用既有：`Policy.child()` 天花板、`ModelRouter` 错误分类、`Session.append()`、`sanitise_child_output()`、`Config.get("federation", ...)`。

## 9. 自检清单（离线可验证）
1. 六家描述符均可从配置解析且 `args_template` 含 `{task}`；
2. 对不存在的可执行文件，healthcheck 返回 unhealthy；
3. `clean_stdout` 对注入的 ANSI/TUI/进度条样本输出无转义与框线字符；
4. 「退出码 0 + 空正文」判失败；
5. 含道歉指纹的输出判失败；
6. 假命令（如 `ping -t`）在 deadline 前被超时路径返回；
7. BadRequest 类错误不触发重试；
8. 配额耗尽 worker 不被 `pick`；
9. 子 worker 请求派生被天花板拒绝；
10. 任务书渲染后含三条纪律与结果分隔符；
11. 会话日志含 federation 事件且可 replay；
12. `dump-config` 下联邦行不触发 `$expr` 求值。

## 10. 最可能失败的地方（自身短板上榜）
1. **我自己（dsh）**是一次性 headless 任务，无长会话协商协议，中途无法追问，只能整包重派；2. 各家退出码语义不可信（0 与失败并存），`judge_success` 是启发式，新噪声即可绕过；3. 跨 CLI 凭据/端点漂移最隐蔽（claude code 的 base_url 坑），healthcheck 查不出「活着但 404」；4. Windows 上杀不干净子进程树，僵尸 worker 占端口；5. 联邦层自身也烧 token：重试+审查叠加成本可能超收益，预算护栏一松即失本。
